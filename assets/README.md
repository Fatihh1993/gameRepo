# Assets Klasörü

Bu klasör oyun görselleri için hazırlandı.

## İçerik

- `images/` - Oyun görselleri, ikonlar, arka planlar

## Gelecekte Eklenebilecekler

- Logo görseli
- Profil fotoğrafları
- Rozet ikonları
- Dil logoları
- Arka plan görselleri

Şu an için uygulama Material Icons ve emoji kullanıyor.
